INSTRUKSI FONT POPPINS
======================

Folder ini harus berisi file font Poppins. Download dari:
https://fonts.google.com/specimen/Poppins

File yang diperlukan (letakkan di folder ini):
  - Poppins-Regular.ttf     (weight 400)
  - Poppins-Medium.ttf      (weight 500)
  - Poppins-SemiBold.ttf    (weight 600)
  - Poppins-Bold.ttf        (weight 700)

Cara download:
1. Buka https://fonts.google.com/specimen/Poppins
2. Klik "Download family"
3. Ekstrak zip
4. Copy 4 file .ttf di atas ke folder ini (assets/fonts/)

Font sudah dikonfigurasi di pubspec.yaml — tidak perlu mengubah apapun
setelah file .ttf ada di folder ini.

CATATAN: File .ttf TIDAK disertakan di repository ini karena ukurannya.
