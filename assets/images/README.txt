FOLDER IMAGES
=============

Letakkan gambar aset aplikasi di sini.

File yang bisa ditambahkan (opsional):
  - logo_kostify.png     (logo app untuk splash/about)
  - ktp_placeholder.png  (placeholder saat scan KTP)
  - avatar_default.png   (avatar default profil)

Format yang didukung: .png, .jpg, .jpeg, .svg, .webp

Sudah dikonfigurasi di pubspec.yaml:
  assets:
    - assets/images/
